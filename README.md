# Market-Volatility-Predictor
This project aims to look at whether market data can be used to predict the estimated volatility 5, 10 and 20 days in the future using different statistical and machine learing concepts. 

My aim with this project is to build my understanding of these concepts from my university classes by applying them to a practical example.

Using different historical stock data from Yahoo Finance, I compared different regression models by using a grid search to get an estimated best parameter for each model and then comparing the Mean Squared Error(MSE) of each of these models.
